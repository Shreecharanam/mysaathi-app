# MySaathi

A general centre-management app for tuition centres, gyms, clinics and small shops.

Built with Flutter. One app, many centres.

## Status

Step 1: a minimal app (login screen) that builds an APK, so the build pipeline is proven before features are added.

## Build

The APK is built automatically by GitHub Actions (see `.github/workflows/build-apk.yml`).
Open the **Actions** tab, pick the latest run, and download the `mysaathi-apk` artifact.

## Roadmap

1. Centre signup / login (Firebase)
2. Centre profile + type (tuition / gym / clinic / shop)
3. People management (students / members)
4. Attendance
5. Fees and payments
6. Member login with own-record-only view
7. Reminders
8. Reports
9. Play Store release
